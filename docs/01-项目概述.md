# 项目概述

## 1. 项目背景

本项目是互联网金融智能客服系统，目标是利用大语言模型提供 7x24 小时在线客服能力，覆盖产品咨询、业务办理指引、常见问题解答等场景，同时保留人工客服介入的扩展能力。

## 2. 项目目标

- 基于 LangChain4j 快速接入大语言模型，屏蔽底层模型差异。
- 通过 Nacos 统一管理应用配置，支持运行时动态刷新。
- 将用户与 AI 的对话内容持久化到 MySQL，满足审计、追溯与运营分析需求。
- 采用 Maven 多模块结构，明确 common / service / biz 三层职责边界。
- 建立基础测试体系，覆盖服务层、数据访问层与 Web 接口层。

## 3. 适用范围

当前版本聚焦对话核心链路：

1. 用户发送消息。
2. 服务端携带历史上下文调用阿里云百炼模型。
3. 用户消息与 AI 回复写入数据库。
4. 通过历史记录接口回放会话内容。

## 4. 术语说明

| 术语 | 说明 |
| --- | --- |
| sessionId | 一次客户咨询会话的唯一标识 |
| ChatMessage | LangChain4j 对话消息抽象 |
| OpenAI 兼容模式 | 阿里云百炼提供的与 OpenAI API 兼容的模型接入方式 |
| Nacos Config | 阿里云 Nacos 配置中心能力 |

## 5. 非目标

本阶段不包含用户鉴权、工单系统、人工客服转接、语音客服、知识库检索增强（RAG）等能力，相关模块可在后续迭代中扩展。
