# 接口设计

## 1. 通用约定

- 基础路径：`/api/v1`
- 请求与响应均为 JSON，编码 UTF-8。
- 统一响应结构：

```json
{
  "code": 0,
  "message": "成功",
  "data": {},
  "timestamp": 1754964000000
}
```

## 2. 发送对话

`POST /api/v1/chat`

请求体：

```json
{
  "message": "你们的产品有哪些？",
  "sessionId": "demo-001"
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| message | string | 是 | 用户消息 |
| sessionId | string | 否 | 会话 ID，缺省时服务端自动生成 |

响应示例：

```json
{
  "code": 0,
  "message": "成功",
  "data": {
    "sessionId": "demo-001",
    "message": "我们目前提供消费贷、理财与支付相关服务。",
    "createdAt": "2026-08-12T10:00:00",
    "modelName": "qwen-plus"
  },
  "timestamp": 1754964000000
}
```

## 3. 查询历史记录

`GET /api/v1/chat/history?sessionId=demo-001`

响应示例：

```json
{
  "code": 0,
  "message": "成功",
  "data": [
    {
      "id": 1,
      "sessionId": "demo-001",
      "role": "USER",
      "content": "你们的产品有哪些？",
      "modelName": null,
      "createdAt": "2026-08-12T10:00:00"
    }
  ],
  "timestamp": 1754964000000
}
```

## 4. 错误码

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未授权 |
| 404 | 资源不存在 |
| 500 | 系统内部错误 |
| 10001 | AI 服务调用失败 |
| 10002 | 数据访问失败 |

## 5. 幂等与安全建议

- 客户端可生成 `requestId` 用于重试去重，当前版本未实现。
- 对话接口建议后续接入限流、内容安全审核与敏感信息脱敏。
