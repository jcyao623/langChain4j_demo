# 测试规范

## 1. 测试分层

| 层级 | 技术 | 覆盖目标 |
| --- | --- | --- |
| 单元测试 | JUnit 5 + Mockito | Service 业务逻辑、公共类 |
| 数据访问测试 | @DataJpaTest + H2 | Repository 查询与排序 |
| Web 测试 | @WebMvcTest + MockMvc | Controller 参数校验与响应结构 |
| 上下文测试 | @SpringBootTest | Bean 装配与应用可启动性 |

## 2. 命名规范

- 测试类：`被测类名 + Test`
- 测试方法：`should + 预期行为`

示例：

```text
ChatServiceImplTest.shouldSaveUserAndAssistantMessages
ChatControllerTest.shouldRejectBlankMessage
```

## 3. 测试原则

- 单元测试不访问真实外部服务，使用 Mockito 隔离。
- 数据库测试使用 H2 内存库，不依赖本机 MySQL。
- 不编写只断言“不抛异常”的空测试。
- 新增业务分支必须补充对应测试。

## 4. 运行测试

```powershell
mvn test
```

运行全部模块测试：

```powershell
mvn -pl biz -am test
```
